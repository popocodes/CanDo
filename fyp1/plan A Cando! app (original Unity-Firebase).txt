CanDo! — Final Master Blueprint 


 1. The Core Identity & ADHD Psychology

 App Goal: A gamified 2D AR mobile app that uses visual prompting and audio chunking to help children with ADHD (ages 5–12) complete chores without task paralysis.
 Mascot (Digital Body Double): Popo, a cosmic cat alien who guides the child, prevents loneliness, and provides immediate emotional feedback.
 Tech Stack: Unity 2D (Frontend) + Google Firebase (Backend).
 ADHD Design Rules:
 No Ticking Numbers: Use visual progress bars (a moving spaceship) instead of numerical countdowns.
 Chunking: Show only one step at a time to prevent cognitive overload.
 Audio First: Read instructions aloud so the child can put the phone down and clean with both hands.
 Asymmetric Gamification: No punishing "broken streaks." Missed days are treated neutrally; successes are celebrated massively.



 2. Frontend vs. Backend: Global Systems

Before diving into screens, your developers need to build these core global engines:

 InBuilt Chore Database (Frontend  Unity `ScriptableObjects`): Chores are prebuilt as modular data templates in Unity. Developers assemble the steps, audio files, and 2D animations in the editor. This means the app works instantly without constantly pinging the database for basic chore data.
 The "SoftLock" Distraction Monitor (Frontend $\rightarrow$ Backend):
 Frontend: A Unity script (`OnApplicationPause`) detects if the child presses the Home button or switches to another app midchore. It instantly pauses the timer and docks a bonus star.
 Backend: Triggers a Firebase Cloud Messaging (FCM) alert to the parent's phone.


 Parent Push Notification Engine (Backend  FCM):
 Alert 1 (Completion): "📸 Mission Accomplished! Leo finished 'Clean Bedroom'. Check the photo!"
 Alert 2 (Distraction): "🚨 Task Paused: Leo left CanDo! at 4:15 PM. Text them to get back on track!"
 Alert 3 (Reward): "🎁 Reward Claimed! Leo spent 50 stars on '30 Mins iPad Time'."



 3. ScreenbyScreen Frontend & Backend Breakdown

 Screen 0: FirstTime Setup (Parent Onboarding)

 Frontend (Unity): Clean UI forms for creating an account, setting a 4digit PIN (saved locally via `PlayerPrefs`), and adding kid profiles (typing names, picking avatar colors).
 Backend (Firebase): Registers the parent in Firebase Auth. Creates the master Family document and Child Profile subcollections in Cloud Firestore.

 Screen 1: The Gateway ("Who is exploring today?")

 Frontend (Unity): A dynamic grid (`GridLayoutGroup`) of the kids' avatars. Kids tap their face to log in instantly. A small lock icon opens a Unity UI Numpad for parents to enter their PIN.
 Backend (Firebase): Reads the Child Profiles from Firestore on boot to populate the grid.

 Screen 2: The Space Base (Kids' Quest Hub)

 Frontend (Unity):
 Space Base: A 2D room they can decorate.
 Hologram Task Board: Shows assigned chores.
 Low Battery Mode: A toggle that instantly swaps complex chores for "Good Enough" microtasks.
 Roulette Wheel: A physicsbased spinning wheel that picks a chore to cure decision paralysis.
 Cosmic Arcade (Exit Strategy): A boarded up arcade machine. When the Task Board hits 0, it visually unlocks. Tapping it opens Cosmic Bubble Pop, a soothing, nolose 2D physics minigame for them to play while waiting for the parent to check their work.


 Backend (Firebase): Fetches today’s assigned chores from Firestore. When the child buys a "Real World Reward" from the shop, it deducts stars from their database balance and sends an FCM Push Notification to the parent.

 Screen 3: Active Chore Mode (MicroStep Flow)

 Frontend (Unity): The handsfree workspace. Displays a single MicroStep Card. Plays Popo's audio voiceover (`AudioSource`). Features a massive "Next" button and a "Show Me!" button.
 Backend (Firebase): None. Runs entirely locally using the `ScriptableObject` data to keep it fast and responsive.

 Screen 4: The 2D AR "Magic Lens" (OnDemand Visual Prompting)

 Frontend (Unity): Triggered by the "Show Me!" button. The background switches to the live device camera using Unity's `WebCamTexture`. A looping 2D Sprite animation demonstrating the physical chore overlays the center of the screen, with Popo pointing at it. Tapping "X" closes it.
 Backend (Firebase): None.

 Screen 5: Proof Photo Shutter & Celebration

 Frontend (Unity): The camera opens full screen: "Scan the room for Mission Control!" The child snaps the picture. The UI freezes, Popo triggers a massive cheering animation, and digital confetti/stars explode on screen.
 Backend (Firebase): Silently uploads the photo file to Firebase Cloud Storage. Updates the task status to "Pending" in Firestore. Sends the Completion FCM Push Notification to the parent.

 Screen 6: Parent Command Center (PIN Protected)

 Frontend (Unity): Utilitarian, standard app lists with 4 tabs: Inbox (Approvals), Task Assigner, Reward Maker, and Settings.
 Backend (Firebase):
 Downloads the kids' proof photos from Cloud Storage.
 Tapping "Approve" writes the new star balance to Firestore.
 Writing new chore assignments and custom realworld rewards pushes that data to Firestore so it appears on the kid's screen instantly.
